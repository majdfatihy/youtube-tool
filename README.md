# 🚀 YT Master Tool (أداة يوتيوب الشاملة)

أداة تعمل داخل المتصفح لسحب بيانات قناة يوتيوب وفلترتها وتصديرها (Excel / CSV / JSON / Google Sheets) عبر YouTube Data API v3.

## الملفات
`index.html` (الأداة) • `about.html` • `privacy.html` • `terms.html` • `promo.html` (دليل مرئي)

## التشغيل
1. أنشئ مفتاح YouTube Data API v3 من Google Cloud Console، ويفضّل تقييده بنطاق موقعك وبهذه الواجهة فقط.
2. ضع الملفات في مجلد واحد وافتح `index.html`.
3. أدخل المفتاح والقناة (`@handle` أو رابط القناة أو `UC...`)، واختر عدد الفيديوهات الأقصى إن أردت، ثم اضغط سحب.

## ملاحظات
- المفتاح لا يُحفظ إلا إذا فعّلت "تذكّر المفتاح".
- تكلفة السحب تقريباً وحدة Quota لكل 50 فيديو (تظهر بعد الانتهاء).
- نوع "قصير" = مدة 3 دقائق أو أقل، وهو تقدير وليس تصنيف يوتيوب الرسمي.
- نسبة التفاعل = الإعجابات ÷ المشاهدات، وتظهر "—" إن أخفت القناة الإعجابات.
