## 📖 نبذة عن المشروع (Overview)

يحتاج صناع المحتوى ومسوقو الفيديو ومحللو السيو (YouTube SEO) إلى رؤية شاملة لكل فيديوهات القناة أو قنوات المنافسين في مكان واحد بدلاً من التصفح اليدوي المرهق.

تتيح **أداة يوتيوب الشاملة (YT Master Tool)** سحب كافة بيانات الفيديوهات (الطويلة و Shorts والبث المباشر) وقوائم التشغيل في ثوانٍ معدودة، مع توفير محرك بحث جراحي يدعم المعاملات المنطقية، ولوحة إحصائيات متقدمة، وإمكانية حفظ أرشيف كامل للقناة في ملف Excel ذكي يمكن إعادة استيراده للأداة في أي وقت دون استهلاك حصة API من جديد.

## ✨ المميزات والخصائص التقنية (Key Features)

* 🔒 **أمان وخصوصية محلية 100% (Client-Side Only):** تتصل الأداة مباشرة بخوادم Google الرسمية (`googleapis.com`) من متصفحك؛ لا يتم إرسال أو تخزين مفتاح الـ API أو بيانات قناتك على أي خادم خارجي.
* 📊 **استخراج شامل لـ 24 عمود بيانات لكل فيديو:**
  * **البيانات الأساسية:** العنوان، الرابط، الصورة المصغرة، نوع الفيديو (`Shorts` / فيديو طويل / بث)، المدة الزمنية، تاريخ ووقت النشر.
  * **الإحصائيات والتفاعل:** المشاهدات، الإعجابات، التعليقات، وحساب **نسبة التفاعل (Engagement Rate)** تلقائياً.
  * **بيانات السيو والتقنية:** الكلمات المفتاحية (Tags)، الوصف الكامل، التصنيف، المواضيع (Topics)، اللغة، الجودة (`HD`/`SD`)، توفر الترجمة، الخصوصية، الترخيص، قيود المنطقة، وتصنيف الأطفال.
* 📂 **تحليل قوائم التشغيل (Playlists Dataset):** خيار لجلب كافة قوائم تشغيل القناة، ومعرفة الفيديوهات غير المدرجة في أي قائمة، والتبديل بين جدول الفيديوهات وجدول قوائم التشغيل.
* 🔍 **محرك بحث جراحي بمعاملات متقدمة (Boolean Search):**
  * البحث داخل العناوين، الوصف، أو الكلمات المفتاحية مع إظهار **سبب التطابق (Why it matched)** وتظليل الكلمات بالأصفر.
  * دعم المعاملات المنطقية: الجمع (`كلمة1+كلمة2`)، الاستبعاد (`-كلمة`)، التخيير (`كلمة1|كلمة2`)، والعبارة الدقيقة بين علامتي تنصيص (`"عبارة كاملة"`).
  * فلاتر حية حسب النطاق التاريخي، أقل عدد مشاهدات، نوع الفيديو، التصنيف، وقائمة التشغيل.
* 📈 **لوحة إحصائيات ورسوم بيانية تفاعلية (Chart.js Dashboard):**
  * 11 مؤشر أداء رئيسي (KPIs): إجمالي ومتوسط ووسيط المشاهدات، معدل التفاعل والإعجاب، التعليقات لكل ألف مشاهدة، المشاهدات اليومية للفيديو، ووتيرة النشر الشهرية.
  * رسوم بيانية لأعلى 10 فيديوهات، تركيبة المحتوى، الأداء الشهري، أفضل أيام النشر في الأسبوع، وتوزيع شرائح المشاهدات.
* 📥 **تصدير واستيراد ذكي متعدد المنصات:**
  * تصدير إلى **Excel (`.xlsx`)** مع تضمين ورقة بيانات مخفية مضغوطة (`Gzip`) تتيح لك **إعادة استيراد ملف الإكسل** للأداة لاحقاً بكل تفاصيله دون الاتصال بالـ API.
  * فتح مباشر في **Google Sheets**، أو التصدير بصيغ `CSV` و `JSON`، أو النسخ الفوري للحافظة.
* 🖼️ **تحميل الصور المصغرة المجمّع (Bulk Thumbnail Downloader):** تحميل الصور المصغرة للفيديوهات المحددة (أو كل النتائج) بأعلى دقة متاحة (`maxresdefault`) مجمعة في ملف مضغوط واحد (`ZIP`) ومسمّاة تلقائياًبعناوين الفيديوهات.
* 🎯 **وضع التركيز وتجربة استخدام مرنة:** التبديل بين عرض الجدول وعرض البطاقات (Cards View)، الوضع المضغوط/المريح، وضع التركيز بملء الشاشة، ودعم كامل للغتين العربية والإنجليزية والوضع الليلي.

## 🛠️ طريقة الاستخدام السريعة (How to Use)

1. **إدخال بيانات الربط:** أدخل مفتاح `YouTube Data API v3` الخاص بك، واكتب معرف القناة (`@handle` أو رابط القناة أو معرف `UC...`).
2. **سحب البيانات:** حدد أقصى عدد للفيديوهات (أو اتركه فارغاً لسحب القناة بالكامل)، وفعّل خيار قوائم التشغيل إن رغبت، ثم اضغط **سحب جميع بيانات القناة الآن**.
3. **الفلترة والتحليل:** استخدم شريط البحث الفوري والفلاتر المتقدمة وتبويب الإحصائيات لدراسة أداء الفيديوهات.
4. **التصدير أو الاستيراد:** صدّر نتائجك إلى Excel أو Google Sheets أو حمّل الصور المصغرة بضغطة زر، ويمكنك في أي وقت سحب وإفلات ملف Excel سابق داخل الصفحة لاستعراضه فوراً.
