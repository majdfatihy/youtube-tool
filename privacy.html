نحن في أداة يوتيوب الشاملة نلتزم بحماية خصوصية بياناتك الشخصية وبيانات قناتك على يوتيوب.

أمان البيانات محلياً: تعمل هذه الأداة بالكامل داخل متصفحك الشخصي عبر استدعاء واجهات برمجة تطبيقات جوجل الرسمية (YouTube Data API v3). نحن لا نقوم بتخزين مفتاح API الخاص بك أو حفظ بيانات فيديوهات قناتك على أي خوادم خارجية.

التخزين في المتصفح: لا يُحفظ مفتاح API إلا إذا فعّلت خيار "تذكّر المفتاح"، ويبقى في متصفحك فقط (localStorage) ويمكنك حذفه بإلغاء الخيار. تُرسل الطلبات من متصفحك مباشرة إلى خوادم Google (googleapis.com) وتخضع لسياسة خصوصيتها، وتُحمَّل مكتبات الرسم والتصدير من شبكة CDN (jsDelivr) والصور المصغرة من خوادم يوتيوب. يُنصح بتقييد المفتاح بنطاق موقعك وبواجهة YouTube Data API فقط.
